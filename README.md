# Kaleena LaBerge — Portfolio website

A responsive static professional portfolio and resume, ready for GitHub Pages. Includes a hurricane-analysis case-study page.

## Publish using GitHub Pages
1. Sign in to GitHub.
2. Create a **public repository** named `KaleenaAnn.github.io` (if your GitHub username is `KaleenaAnn`).
3. Upload `index.html` and `hurricane-study.html` to the repository root.
4. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
5. Visit `https://KaleenaAnn.github.io/` after GitHub finishes deploying.

## Before publishing
- Verify current employment and exact dates. The site deliberately does not list a current position at Embraer pending confirmation.
- Add sanitized, independently shareable R scripts and figures to the hurricane case study; verify the final study statistics.
- Check public contact information, and check links after deployment.
- Keep private client information, controlled documentation, and restricted datasets off GitHub.
